# Campaign Create Patch

이 패치는 샘플 데이터 테스트 이후 실제 운영용 첫 기능을 추가합니다.

## 추가 기능

- 관리자 대시보드의 `새 캠페인` 버튼
- 캠페인명 / 브랜드명 / SKU명 / 상품명 / 브랜드 컬러 / 해시태그 입력
- Firestore에 `campaigns`, `campaignTabs`, `guideSections`, `guideItems` 자동 생성
- 세부탭 단위 공유 링크 자동 생성
- 공개 / 미공개 상태 변경
- 캠페인 복제
- 캠페인 아카이브

## 테스트 순서

1. `/admin` 접속
2. `새 캠페인` 클릭
3. 필수 항목 입력
4. 상태를 `공개`로 선택하거나 생성 후 체크 버튼으로 공개
5. 표의 공유 링크 열기
6. `/guide/{shareToken}` 페이지가 열리는지 확인

## 주의

아직 이번 단계에서는 상세 항목 편집 화면은 없습니다. 다음 단계에서 SKU 세부탭 편집 화면을 추가합니다.
