# 통합 요구사항 패치

이 패치는 Firebase Client SDK 기반으로 검증된 현재 구조 위에 다음 운영 기능을 추가합니다.

## 포함 기능

- 캠페인 목록에서 SKU 세부탭 편집 화면 진입
- `/admin/tabs/[token]/edit` 편집 화면 추가
- 기본 정보 / 상품 소개 / 콘텐츠 필수사항 / 주의사항 섹션 편집
- 항목 추가, 수정, 삭제, 복구
- 항목 위/아래 이동
- 상품 소개 항목은 소구 포인트 타입으로 관리 가능하며 최대 5개까지 제한
- 촬영 시 주의사항은 고정 템플릿으로 복원 가능하게 저장 시 보정
- 투고 시 주의사항은 관리자가 직접 작성
- 이미지, 영상 파일, YouTube, Google Drive, 외부 URL 첨부
- 항목당 첨부 최대 5개 제한
- Firebase Storage 파일 업로드 지원
- 우측 휴대폰 크기 미리보기
- 저장 즉시 `publicGuides/{shareToken}` 문서가 갱신되어 공개 페이지에 반영
- 공개 가이드 페이지에서 이미지/영상/YouTube/Drive/외부 링크 표시

## 적용 후 필요한 Firebase Console 작업

Firestore Rules와 Storage Rules를 ZIP 안의 `firebase/` 폴더 내용으로 다시 적용하세요.

## 아직 별도 단계로 남겨둔 기능

- XLSX 오리엔시트 업로드 → 자동 파싱
- GPT-5.4 API로 한국어 원문 → 일본어 가이드 자동 생성
- 전사 공통 용어집 편집 화면

위 기능은 다음 패치에서 API와 UI를 분리해 붙이는 것이 안전합니다.
