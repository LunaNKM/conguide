# Dashboard Premium Redesign Patch

## 변경 사항

1. `/admin` 하단의 운영 흐름 카드와 샘플 모바일 미리보기를 제거했습니다.
2. 상단의 개발용 `샘플 데이터` 버튼을 제거했습니다.
3. 관리자 대시보드를 프리미엄 SaaS/엔터프라이즈 운영툴 톤으로 재디자인했습니다.
4. 사이드바, 상단바, 상태 카드, 검색창, 테이블, 버튼, 모달 업로드 영역의 시각적 완성도를 개선했습니다.

## 디자인 방향

- 데이터 밀도는 유지하되 노이즈를 줄이는 대시보드 구조
- 큰 여백, 명확한 상태 카드, 얇은 보더와 부드러운 그림자
- Vercel/Linear/Stripe류 SaaS에서 자주 쓰이는 절제된 흑백 기반 UI + 브랜드 그린 포인트
- 실제 운영자가 캠페인 상태와 작업 버튼을 빠르게 식별할 수 있는 정보 계층
