# Logo / Preview Scroll / Readability Patch

적용 내용:

1. 편집 화면 우측 휴대폰 미리보기 영역에 마우스를 올리고 휠로 스크롤할 수 있도록 `preview-screen`을 내부 스크롤 컨테이너로 변경했습니다.
2. 공유 모바일 화면 우상단에 회사 로고를 표시하도록 `GuidePage`를 수정했습니다.
3. 캠페인 생성 시 공식 URL이 감지되면 Clearbit Logo API 기반 로고 후보를 자동 적용하고, URL이 없으면 브랜드명 기반 임시 로고를 넣습니다.
4. 편집 화면에서 로고 URL을 직접 수정하거나 이미지 파일을 업로드할 수 있습니다.
5. 각 항목별로 공유 화면 글자 크기 `작게 / 기본 / 크게`와 `강조 표시`를 직접 설정할 수 있습니다.
6. 모바일 공유 화면의 본문 줄간격, 제목 굵기, 리스트 bullet, strong 강조 스타일을 조정해 가독성을 개선했습니다.

주의:

- 로고 자동 적용은 오리엔시트/기본 정보 안에 공식 URL이 있을 때 가장 잘 작동합니다.
- 공식 URL이 없으면 실제 회사 로고가 아니라 브랜드명 기반 임시 로고가 적용됩니다.
- 실제 로고는 편집 화면에서 직접 업로드하거나 회사 로고 URL을 입력해 교체할 수 있습니다.
